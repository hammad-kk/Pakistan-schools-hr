# 🎓 Headstart HR Suite

**HR Automation Platform for Pakistani Schools** + Labour Law Compliance AI

## ⚡ Features

✅ **9 HR Modules** - Talent Acquisition, Policy, Performance, Relations, Training, Engagement, Succession, Compliance, Law Checker
✅ **40+ Workflows** - Job descriptions, interviews, policies, terminations, audits, etc.
✅ **AI-Powered** - Gemini AI generates contextual, legally-compliant outputs
✅ **Pakistan Labour Law** - 15+ laws embedded (EOBI, PESSI, IC&E, Factories Act, etc.)
✅ **PDF Export** - Save outputs as professional documents
✅ **Save Templates** - Bookmark workflows for quick reuse
✅ **100% Free & Open Source**

## 🚀 Quick Start

### 1. Get API Key (Free)
- Go to: https://aistudio.google.com
- Sign in with Gmail
- Click **Get API Key** → **Create API Key**
- Copy the key

### 2. Launch App
- **Live:** https://hammad-kk.github.io/Pakistan-schools-hr

### 3. Use It
1. Paste your API key
2. Add context (e.g., "Senior Teacher, F-7 Campus, 5 years tenure")
3. Click a workflow
4. AI generates output
5. Copy, export as PDF, or save

## 📋 Pakistan Labour Laws Covered

- IC&E Ordinance 1968 (Contracts, termination, notice)
- EOBI Act 1976 (Pensions, registration)
- PESSI (Medical, maternity)
- Factories Act 1934 (Hours, overtime)
- Minimum Wages Ordinance 1961
- Workmen Comp Act 1923 (Accidents)
- Maternity Ordinance 1962 (12 weeks paid)
- IRA 2012 (Trade unions)
- Payment of Wages Act 1936
- Workers Welfare Fund 1971
- Disabled Persons Ordinance 1981 (2% quota)
